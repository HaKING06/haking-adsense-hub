Geleneksel tek sunucu yerine kenar (edge) ağı neden fark yaratır?

Tek bir veri merkezinde (örneğin yalnızca ABD Doğu kıyısında) çalışan klasik bir VPS’e Türkiye’den veya Avrupa’dan bağlanan bir kullanıcı, ilk baytı (TTFB) almadan önce yalnızca fiziksel ışık hızı ve TLS el sıkışması nedeniyle 180–280 ms kaybeder. Cloudflare Workers + Static Assets mimarisinde HTML, CSS, JavaScript ve WebP görseller kullanıcıya coğrafi olarak en yakın kenar düğümden sunulur; API proxy veya hafif dinamik mantık gerektiğinde aynı dağıtım içinde çalışan Worker devreye girer.

<code>assets</code> bağlamasıyla hibrit statik + dinamik tasarım

SPREAD V11.1 ve CSNAME projelerinde statik arayüz dosyaları doğrudan kenar önbelleğinden servis edilirken, harici piyasa verisi veya CORS aşımı gereken uç noktalar aynı wrangler.toml içindeki hafif Worker kodundan yürütülür:

wrangler.jsonc minimal statik + worker kurulumu
{
  "name": "ornek-servis",
  "main": "src/worker.js",
  "compatibility_date": "2026-11-01",
  "assets": {
    "directory": "./public",
    "binding": "ASSETS"
  }
}

Bu yapı, yüksek trafik dalgalanmalarında sunucu çökmesi riskini ortadan kaldırır ve sabit aylık VPS faturası olmadan birden fazla canlı alt alan adını (*.haking.tr) sürdürmeyi mümkün kılar.

<code>_headers</code> ile tarayıcı güvenliği ve önbellek disiplini

Her statik dağıtımda X-Content-Type-Options: nosniff, Referrer-Policy: strict-origin-when-cross-origin ve görseller için uzun süreli Cache-Control: public, max-age=31536000, immutable başlıklarını tanımlamak hem güvenlik skorunu hem tekrar ziyaret hızını belirgin biçimde yükseltir. Ancak HTML belgelerinde agresif uzun önbellek kullanılmamalı; aksi halde yeni sürüm yayınlandığında kullanıcılar saatlerce eski sayfayı görebilir.

Sıkça Sorulan Sorular

Cloudflare Workers üzerinde ağır Node.js kütüphaneleri çalışır mı?

Workers V8 izolatları üzerinde çalışır; dosya sistemi erişimi veya yerel C++ eklentisi gerektiren ağır işlemler için ayrı bir Node.js/Python sunucusu (ör. Haking Chat’teki Socket.IO sunucusu veya HaKING AI’daki FastAPI) kullanmak daha doğrudur.
